Todos los proyectos que se crean en Symposium siguen una estructura determinada en cuanto a las secciones del menú en el website: “Inicio”, “Fechas”, etc. Pero si esta disposición no se ajusta al proyecto que estás creando, es posible editar el menú completamente para cambiar los literales o incluso ocultar botones.

## Editando el menú

Dentro del grupo Diseño se encuentra *“Menú del proyecto”*.

![](/media/crowdfunding/menu_proyecto.png?w=290&align=center)

Cada sección o menú de la web del proyecto está representada por un cuadro amarillo. Este menú dispone de una serie de utilidades:

- **Variar el orden**: para variar el orden de las secciones hay que hacer clic y, sin soltar, arrastrar un recuadro amarillo hacia arriba o hacia abajo. Esto determinará cómo aparecen esos menús en la web del proyecto.
- **Editar el nombre**: para cambiar el nombre a un menú, haz clic sobre el botón “Editar” a la derecha del nombre del elemento.
- **Esconder un elemento**: pulsando en “Esconder” se ocultará un elemento del menú en la web.
- **Limitar la visibilidad de un menú a sólo los participantes**  que tengan confirmada su aportación económica al proyecto.
- **Anidar elementos dentro de un contenedor**: si añadimos un contenedor, usando el botón "Añadir contendor", podemos arrastrar elementos dentro de este contenedor para que formen un submenú.

Las secciones personalizadas o [nuevas páginas](/docs/eventos/contenido/nuevas-paginas) que el autor haya creado se mostrarán anidadas dentro del submenú “Más…”. Para sacarlas al nivel superior deben ser arrastradas fuera del contenedor "Más…". Esto mismo ocurre con la sección Ficheros, que se mostrará dentro del menú "Documentación" de manera predeterminada.

![](/media/crowdfunding/personalizar_menu.png?w=866&align=center)

Cada plantilla de proyecto tiene un número máximo de elementos que pueden mostrarse en el menú. Si se diseña el menú de forma que se supere ese máximo, los elementos se colocarán dentro de la pestaña "Más".
