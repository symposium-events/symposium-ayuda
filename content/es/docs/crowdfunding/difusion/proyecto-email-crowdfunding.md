Symposium proporciona a los autores de proyectos crosdfunding una herramienta para la difusión por email. Para ello, el autor dispone de una plantilla de email básica, diseñada por Symposium.

A criterio de los Administradores de la plataforma, los autores pueden disponer, también, de [plantillas personalizadas de resumen de proyecto](/docs/administracion/diseno/plantillas-de-resumen-evento). La plantilla original está maquetada para ser compatible con la mayoría de clientes de correo electrónico. Para las plantillas personalizadas, la compatibilidad depende del diseñador de cada una.

![menu_difusion_eventoemail.jpg](/media/crowdfunding/menu_proyectoemail.png?w=290&align=center)

## Crear resumen

La funcionalidad comienza con el botón Crear resumen. Al hacer clic en él, Symposium crea automáticamente una vista del proyecto aplicando la plantilla genérica. Se muestra en un panel emergente y contiene elementos básicos del proyecto:

- Logotipo de la institución
- Imagen principal del proyecto
- Título
- Texto breve del campo "Descripción" del menú Datos básicos
- Un cuadro con las fechas de apertura y cierre
      - posibilidad de enlazar las fechas con una aplicación de calendario
      - posibilidad de mostrar la ubicación en una sesión de Google Maps
- El bloque completo del campo "Descripción", que es lo que aparece en la home la página del proyecto
- Un cuadro con datos de contacto
- Un botón para enviar por email una prueba del mensaje
- Un botón para descargar un fichero HTML con el contenido de esta vista

![](/media/crowdfunding/proyecto_email.png?w=720&align=center)

## Enviar email de prueba

Muestra un nuevo panel emergente que permite indicar una dirección de email de destino para remitirle la vista previa que se ha obtenido. Para ello, es preciso marcar el check que garantiza que se dispone de permiso del destinatario para realizar el envío. Sólo es posible enviarlo a una dirección, dado que se trata de una prueba. Symposium no proporciona servicio de envío masivo de email.

## Descargar HTML

Lanza una descarga inmediata de un fichero de texto plano con extensión .html con el contenido y la maquetación y estilos de la vista previa. El autor puede lanzarlo a los destinatarios mediante cualquier aplicación de envíos masivos de correo electrónico, como Mailchimp o similar.

Este documento HTML es un producto final y no se almacena en Symposium. Se puede generar de nuevo tantas veces como sea necesario.
