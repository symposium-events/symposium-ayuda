En esta sección podemos añadir nuevos administradores del portal que pueden acceder al panel de administrador del sitio, así como eliminar los existentes. Únicamente habrá que indicar el correo electrónico.

![](/media/admin/captura_de_pantalla_2013-03-21_a_la_s_11.06.21.png?align=center)

En caso de no localizar a un usuario con ese correo electrónico, el sistema preguntará para enviar un correo con el enlace para registrarse en la plataforma como administrador.

![](/media/admin/captura_de_pantalla_2013-03-21_a_la_s_11.07.50.png?align=center)

![](/media/admin/invitacion_admin_um.png?align=center)

El correo electrónico puede ser cualquiera, sea o no perteneciente a la institución. Una vez el usuario que recibe el correo hace clic en el link para abrir la pantalla de registro, deberá usar como correo electrónico el mismo que se ha utilizado al enviar la invitación.
