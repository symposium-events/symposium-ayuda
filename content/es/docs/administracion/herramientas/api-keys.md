Una API key es la clave de seguridad que sirve como medio de autenticación del usuario para el uso de los servicios proporcionados por la API.

En este apartado podrás consultar tus API key generadas, el servicio de API a la que pertenece y la fecha de expiración. Si necesitas renovar cualquiera de tus API key, por favor, ponte en contacto con servicio de Soporte de Symposium para que generen una nueva.

Podrás volver a consultar las nuevas API keys en este panel.

Solamente podrás tener una API key por servicio de API. Recuerda que con la API key pueden obtenerse listados de datos, por lo que es importante que no confíes el acceso a cualquier usuario.
