Este menú lo encontrarás en el Panel de Administración, en la sección de Diseño:

![](/media/admin/estilos_css.png?w=250&align=center)

Permite añadir un estilo CSS a todo el portal ya sea con el editor en linea o subiendo el archivo.

El estilo que decidas añadir sobrescribirá el estilo por defecto. También aquí podrás configurar que el estilo por defecto deje de mostrarse. Debes llevar cuidado, pues si desactivas este check, el estilo por defecto y las partes del estilo CSS que no hayas definido se verán en HTML plano.

![](/media/admin/estilos_css_1.png?w=750&align=center)

Es posible además personalizar el icono que se muestra en la ventana del navegador para que corresponda a la imagen corporativa de la institución. Es importante que el archivo de la imagen tenga el formato .ico para poder cargarlo en la plataforma.
