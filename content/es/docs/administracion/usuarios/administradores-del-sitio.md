Como usuario Administrador, en esta sección puedes añadir o desactivar a otros Administradores del sitio para que tengan acceso a todas las secciones del Panel de Administración.

## Dar de alta a un nuevo Administrador

Cualquier usuario que ya tenga el rol de Administrador en la plataforma, puede dar de alta a otro Administrador que comparta los mismos permisos que los demás.

Para añadir a un nuevo Administrador, indica su correo electrónico en el recuadro:

![](/media/admin/adminisrador_del_sitio.png?w=750&align=center)

En caso de no localizar al usuario con ese correo electrónico, el sistema preguntará para enviar un correo con el enlace para registrarse en la plataforma como Administrador.

![](/media/admin/administrador_del_sitio_aviso.png?w=400&align=center)

![](/media/administrador_invitacion.png?w=400&align=center)

El correo electrónico puede ser cualquiera, sea o no perteneciente a la institución. Una vez el usuario que recibe el correo hace clic en el link para abrir la pantalla de registro, deberá usar como correo electrónico el mismo que se ha utilizado al enviar la invitación.

En el caso de que se trate de un usuario a registrado posteriormente en la plataforma, directamente se le enviará una invitación notificándole su nuevo rol como Administrador del sitio.
