Esta sección se encuentra en el menú Usuarios del Panel de Administración.

![](/media/admin/usuarios_de_soporte.png?w=250&align=center)

En este panel puedes añadir a Usuarios de soporte que se encarguen de ofrecer asistencia a otros usuarios de la plataforma, pudiendo suplantarlos en el caso de que sea necesario. Este rol únicamente puede acceder al Panel de Administración para suplantar, pero no tendrá permiso para acceder a las demás secciones del Panel y nunca podrá suplantar a un usuario con rol de Administrador.

## Dar de alta a un Usuario de soporte

Para dar de alta a un Usuario de soporte, tendrás que indicar su dirección de correo electrónico en el campo en el que se solicita. Si se trata de un usuario ya registrado anteriormente en la plataforma, este recibirá una invitación. En el caso de tratarse de un usuario no registrado, tienes la opción de enviarle una invitación para que se registre y de esta forma aceptar el rol de Usuario de soporte.

En cualquier momento puedes desactivar a un Usuario de soporte.

![](/media/admin/anadir_usuario_soporte.png?w=750&align=center)
