This section is in the **Tools** menu of the financial management panel.

![](/media/events_list/events_list_menu.png?w=221&align=center)

In this section you can build a list of events, which can be filtered by date. You can also export this list to an Excel file.

![](/media/events_list/events_list.png?w=745&align=center)

The list also includes a breakdown of which users took part in organizing the event and which accountants supervised it, where applicable.

These breakdowns can be accessed by clicking the button with a plus sign (+) to the right of each row, or in the corresponding column of the Excel file.
