This section lets you publish files that website visitors can download. It is a list of documents that can usually be classed as Documents or as Notices.

![](/media/crowdfunding/archivos_proyecto.png?w=290&align=center)

Website visitors will be able to access this section from the "Documentation" header menu.

To upload a file, click "*Add file*" and enter a description in the menu that opens. Select the file type (Document or Notice) and locate the file on your computer. The maximum size allowed for uploading a file is **100 MB.** Depending on your network speed and the size of the file, you will have to wait a few seconds until the progress bar completes. Once it is complete, click "Save".

![](/media/crowdfunding/archivos_proyecto_panel.png?w=866&align=center)
