From this menu you can modify the initial details configured when [creating the project](/docs/crowdfunding/creando-y-editando-un-evento/creando-un-proyecto-nuevo).

![](/media/crowdfunding/datos_basicos.png?w=290&align=center)

You can modify these details at any time, as often as necessary. The details that can be modified from this menu are the following:

- Project title.
- Visibility on the platform's home page.
- Organizer, contact details and custom web address.
- Home pages on which you want to publish your event, if the instance has more than one.
- Custom subject for the email messages received by donors.
- Pretty web address, using the URL shortener built into Symposium.
- Subject categories, one or more to choose from, to help the website's search engine ranking.
- Keywords, also to help the website's search engine ranking.
- Funding target, an important detail, since it is the amount you hope to reach with the donations you receive.
- Opening and closing dates for receiving financial contributions.
- Basic description, limited to 100 words, which will not be shown on the website, since its purpose is to help the page's search engine ranking.
- (Full) description, which is the content that will appear on the project's main page.

Always remember to save your changes with the **Save** button, at the bottom right of the form.
