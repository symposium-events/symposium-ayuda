Although search engines now take a web page's metadata into account less, you can still use it to improve your project website's ranking somewhat. It is an accurate description of the content, which you can write in the **Promotion > Metadata** menu.

![](/media/crowdfunding/menu_metadatos.png?w=290&align=center)

As a strategy to make the most of this field, use short, easy-to-understand sentences, or keywords that are not in the title of the project page. Remember, however, that meta fields are less important today than they were a few years ago.

![](/media/crowdfunding/metadatos_proyecto.png?w=866&align=center)

A good choice of metadata can improve the visibility of the project website, increasing the number of visits it receives.
