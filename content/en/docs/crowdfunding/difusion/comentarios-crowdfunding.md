As the project author, you may want participants to be able to write comments to encourage interaction between them. This option is disabled by default and is enabled in the **Promotion > Comments** menu.

![](/media/crowdfunding/menu_comentarios.png?w=290&align=center)

Enable comments by ticking the **Enable comments?** checkbox.

![](/media/crowdfunding/comentarios_proyecto.png?w=866&align=center)
