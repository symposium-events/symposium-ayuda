The author of a project can set up the application to send a personalized welcome message to donors who have made a financial contribution to the project. This feature is optional and, if used, the text will be included in the confirmation message that Symposium already sends to donors by default. The tool is in the **Sponsorships > Welcome message** menu.

![](/media/crowdfunding/mensaje_de_bienvenida.png?w=250&align=center)

In this panel the feature can be enabled with a checkbox. Further down there is a text box with extensive formatting options to personalize the message you want to send.

Bear in mind that the text you write will be included in the email with generic text that Symposium sends to donors who take part in the project.

![](/media/crowdfunding/texto_mensaje_de_bienvenida.png?w=750&align=center)

In multi-language projects this feature must be enabled and the content saved separately and individually for each language version of the website. To make this easier, each language has a **Copy original content** button, which copies the message content of the project's main language into the text box. If it is not translated and adapted, the same message can be sent to all participants.

If the translation into other languages is not done, no personalized text will be sent.
