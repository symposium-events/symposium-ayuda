Locations are sites, buildings, addresses or places to which spaces are linked. They act as a container for grouping them.

The **Manage locations** menu gives access to viewing, editing and creating them.

![](/media/admin/ubicaciones.png?w=250&align=center)

With the **New location** button you can create as many as you need, simply by entering a descriptive name. It is good practice to use easily recognizable addresses or building names.

![](/media/admin/nueva_ubicacion.png?w=500&align=center)A location can be renamed at any time. It can only be deleted if it has no linked spaces.

![](/media/admin/gestion_ubicaciones.png?w=500&align=center)
