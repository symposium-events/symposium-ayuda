An API key is the security key that serves as the means of authenticating the user for the use of the services provided by the API.

In this section you can view the API keys you have generated, the API service each one belongs to and its expiry date. If you need to renew any of your API keys, please contact Symposium Support so that they can generate a new one.

You can view the new API keys again in this panel.

You can only have one API key per API service. Remember that the API key can be used to obtain data listings, so it is important that you do not entrust access to just any user.
