This menu lets you create custom widgets that you can embed in any websites you wish. The widget will contain cards with the image, title and date of the events you choose, giving them wider exposure.

From the **Administration panel**> **Tools**> **Event component** menu you can create as many components as you need: ![](/media/archivos_asistentes/componente_eventos.png?w=250&align=center)To create a widget, click **Add item:**

1. **Choose a name for the widget.**
1. **Select the number of columns**: two, three or four, depending on how many event cards you want to appear per row.
1. **Select the events you want the widget to show and their order.**
1. **Enter the domain or domains of the pages where the widget will be embedded.** This ensures that it will not work on any other website. If you want it to work on any domain, which we do not recommend, simply leave the box blank.
1. **Finally, get the widget's HTML code to embed in any other website.**
