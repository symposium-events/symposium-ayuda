You can embed a list of events with their links in any website you manage by means of a custom widget. This gives your events wider exposure. You can create as many widgets as you need in **Administration panel > Tools > Events widget:**

**![](/media/admin/widgets.png?w=250&align=center)**

You can create as many widgets as you need. Each one will show a list of events according to the criteria you specify.

To create a widget, click **"Add item":**

1. **Choose a name for the widget**
1. **Filter the events you want to show in the list by:**
   1. The event category or categories you want to specify
   1. The event type or types
   1. Directory or directories
   1. Location or locations
   1. Front page or pages on which the events are published
1. **Select your widget's design**
   1. Color
   1. Height
   1. Width
   1. Number of events shown
1. **Finally, get the widget's HTML code, which you can embed in any other web page.**

The result will look similar to this:

![](/media/admin/captura_widget.png?w=250&align=center)
