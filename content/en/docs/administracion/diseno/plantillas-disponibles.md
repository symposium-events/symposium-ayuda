In this section you will find all the templates the platform has, including your own custom ones as well as the default ones. You can select which of them you want to be available to event organizers when they create their events. It also lets you set a default template for all events.

In this section you can also create custom templates to send an event summary by email. See more information on how to [customize the event summary template](/docs/administracion/diseno/plantillas-de-resumen-evento).
