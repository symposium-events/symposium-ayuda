All Symposium event instances are integrated with the Emagister Eventos portal, so all the events created are automatically published on the Emagister portal, gaining greater promotion and reach.

If you do not want a particular event to be published on the Emagister Eventos portal, you can do so from this same section. Just enter the event's identification number and untick the "Visible?" check box. The event will still be visible on your institution's home page; it will simply no longer appear on the Emagister Eventos portal.

![](/media/admin/emagister.png?w=750&align=center)

**Note**: the event's identification number is a numeric value that you can find in the event's own URL.
