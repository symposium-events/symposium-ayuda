Event organizers can specify a type for each event they create. Symposium includes a list of event types by default. The institution's administrators can create their own lists of event types for their platform.

![](/media/admin/tipos_de_eventos_personalizados.png?w=800&align=center)

## Creating new event types

To create a new event type, select **Use custom event types** in the options bar.

When creating a new event type, you can optionally add its name translated into the other languages.

![](/media/admin/curso_intensivo.png?w=750&align=center)

## Configuring the event types shown

In the first section, there is a drop-down list where you can configure which list of event types organizers will have available.

- Use platform event types.
- Use custom event types.
- Combine platform event types with custom event types.
