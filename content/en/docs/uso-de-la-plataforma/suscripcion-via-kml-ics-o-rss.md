Symposium lets you subscribe in different ways to the events being created on the platform. In the subscriptions section, users have these three formats available for each geographical location and category in which events have been created.

![](/media/suscripcion_via_kml_ics_o_rss/suscripciones.png?w=601&align=center)

By clicking the format icon (or right-clicking and choosing "Copy link address") we can get the corresponding file.

## KML

KML is a file format for geographical locations popularized by Google in its [Google Maps](http://maps.google.es/) and [Google Earth](http://www.google.es/intl/es/earth/index.html) tools, although it can also be used in other utilities such as GPS navigators.

Subscribing via KML gives you a view of the geographical proximity of the events that will take place in a given location, as well as a map of the academic activity in the selected region.

## ICS

ICS is the most popular format for subscribing to calendar or electronic diary events. Widely used tools such as Google Calendar, Apple iCal or the generic ones used on smartphones can read these files and add them to the user's calendar.

This way, you can have an academic calendar showing the dates and locations of the upcoming events in a given location or category.

## RSS

RSS is the news aggregation format par excellence. For more than a decade this format has made it possible to extract summarized content from the main websites so that it can be read together from different devices.

Subscribing to a Symposium RSS feed lets you receive upcoming events as if they were news items. Their title, description and event dates will be available to you as soon as they are published, letting you keep up to date with the activity in your location or favorite category.
