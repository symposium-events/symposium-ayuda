## Can a user resume a payment that has been rejected?

Currently, only payments that can be relaunched from the payment platforms themselves can be resumed. In other words, SYMPOSIUM by Emagister does not offer this functionality, but delegates it to the payment platforms.

If the payment platform allows it, the user can relaunch the payment. When the financial administrator receives the new notification, they can validate the payment and the attendance will become effective again.

When a payment is rejected the attendance is cancelled, so the user must register again if they want to restart the process and make a new payment.

## Can the statuses a payment has gone through be viewed?

From the Accounting panel, in the [Manage event payments](/docs/gestion-economica/herramientas/gestionar-pagos-de-un-evento) section, we can list all the payments made for that event.

When we expand the details of one of the payments we can see details such as the payment receiver where it was received. In these same details there is a Status updates section at the bottom. Clicking on it expands the status history, including the date and the comment made by the relevant financial administrator.
