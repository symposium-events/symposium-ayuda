This menu is designed so that you can share your activity in Symposium anywhere. The option is available in the **Configuration** > **Tools** > **Share** panel.

![](/media/admin/herramienta_compartir.png?w=200&align=center)

If you have a blog or website you can share information about the events you organize and the ones you attend.

![](/media/admin/compartit.png?w=750&align=center)

Set the size of the box you want to display, specify a maximum number of entries and press the " *Update*" button. A code will be generated for you to include in your blog or website.

![](/media/admin/actividad_compartida.png?w=750&align=center)
