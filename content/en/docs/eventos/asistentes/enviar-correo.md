Sometimes the Organizer of an Event needs to send a message to one attendee, to a group of them or to any other group of users. Finding each person's address is usually a tedious, time-consuming task, but since that information is already in Symposium, you can use this tool in the **Attendees > Send email attendees** menu.

![](/media/panel_organizador/enviar_correo_asistentes.png?w=250&align=center)

The panel is an email composer with the usual basic controls of this kind of application:

1. **Recipient selector**
1. **Subject** of the notification
1. **Recipients who will receive a copy**
1. **Message body** to be sent

## Recipient selector

A list of items to choose from is shown. It is organized in two sections, each containing different items:

- **Groups**: lets you send the message to sets of users according to some criteria:
      - Users:
         - who have submitted papers
         - with pending papers
         - with confirmed papers
         - with rejected papers
      - All attendees
      - Attendees
         - confirmed
         - pending
         - rejected
- **Users**: a list of users, as many as there are in the Event. This list can be very long, but it lets you send a message to a single user or to a selected group of them.

The list box allows multiple selection. When you want to send the message to several groups or several users, or a combination of them, you can select the first one with the mouse and then, while holding down the Control key on the keyboard, select the others.

## Subject

A text box for the Subject of the email to be sent.

## Recipients who will receive a copy

A text box where you can type by hand the email addresses of the recipients you want to receive copies of the message. It is optional and is enabled by ticking a checkbox.

## Message body

The text is written in a box that allows several simple formatting options. Since it is an email, there is no defined maximum length.
