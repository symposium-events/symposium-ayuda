As the Event Organizer, you may want platform users to be able to write comments on the Event to encourage interaction among them. This option is enabled or disabled in the **Promotion > Comments** menu.

![](/media/admin/comentarios.png?w=250&align=center)

Enable Comments by ticking the Enable comments? checkbox.

![](/media/comentarios/activar_comentarios.png?w=744&align=center)

Once enabled, users will be able to write comments from the main page of the Event using the text box provided for this purpose.

![](/media/comentarios/ver_comentarios.png?w=373&align=center)
