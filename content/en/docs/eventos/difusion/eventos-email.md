Symposium provides Event Organizers with a tool to promote a given event by email. For this, the Organizer has a basic email template, designed by Symposium.

At the discretion of the platform Administrators, Organizers may also have [custom event summary templates](/docs/administracion/diseno/plantillas-de-resumen-evento). The original Symposium template is laid out to be compatible with most email clients. For custom templates, compatibility depends on the designer of each one.

![menu_difusion_eventoemail.jpg](/media/menu_difusion_eventoemail.jpg?w=167&align=center)

## Create summary

The feature starts with the Create summary button. When you click it, Symposium automatically creates a preview of the event applying the generic template. It is shown in a pop-up panel and contains basic elements of the event:

- Institution logo
- Main image of the event
- Title
- Short text from the "Basic description" field
- A box with the dates and the location of the event
      - option to link the dates with a calendar application
      - option to show the location in a Google Maps session
- The full block of the "Description" field, which is what appears on the home page of the event
- A box with the event contact details
- A button to send a test of the message by email
- A button to download an HTML file with the content of the event summary

![](/media/wiki/evento_email.png?w=595&align=center)

## Send test email

Shows a new pop-up panel that lets you enter a destination email address to send the preview obtained to. To do so, you must tick the checkbox confirming that you have the recipient's permission to send it.

## Download HTML

Immediately starts the download of a plain text file with an .html extension containing the content, layout and styles of the preview. With this, the Organizer gets an HTML document that can later be distributed using any bulk email application.

This HTML document is a final product and is not stored in Symposium. If necessary, it can be generated again as many times as needed.
