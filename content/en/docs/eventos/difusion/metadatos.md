Although search engines currently give less weight to a page's metadata, you can still use it to improve your Event website's ranking somewhat. It is an accurate description of the content of the Event website, which you can write in the **Promotion > Metadata** menu.

![](/media/panel_organizador/metadatos.png?w=250&align=center)

As a strategy to get the most out of this field, use short, easy-to-understand sentences, or keywords that are not in the title of the Event page. Remember, however, that meta fields are less important nowadays than in the past decade.

![](/media/panel_organizador/metadatos2.png?w=750&align=center)

A well-chosen selection of metadata can improve the visibility of the Event website, increasing the number of visits it receives.
