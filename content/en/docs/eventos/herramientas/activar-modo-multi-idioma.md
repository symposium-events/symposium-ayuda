You can read the following article for more information about [multi-language support](/docs/eventos/herramientas/soporte-multi-idioma)

Symposium makes it easy to create and manage multi-language Events. The underlying idea is that an Event is initially created in one language and the Organizer decides whether they want its website to have versions in other languages. Symposium supports, in alphabetical order, Catalan, English, Italian, Portuguese and Spanish.

Multi-language support can be enabled in the Tools > *Enable multilanguage* menu.

![](/media/panel_organizador/multi_idioma.png?w=250&align=center)

Enabling this mode makes it possible to edit the Event content independently in each available language, so that users can access it in the language of their choice.

To enable it, tick the "Do you want to enable multi language mode?" checkbox. When you do so, new options will appear on that management screen.

![](/media/panel_organizador/idioma.png?w=750&align=center)

The multi-language mode screen itself also includes a detailed description of what enabling this mode involves and how to modify its content.

## Editing the Event in multi-language mode

Once multi-language mode has been enabled, all the changes you make to the Event will only take effect for the language active on the platform at that moment. The versions in other languages will not be affected, and you will have to decide whether to replicate the content in them.

To make editing and control easier, from this moment on a notice will be visible in the right margin of the management application. This floating box will always tell you that the changes you make will only be visible in the version of the website in that same language. This notice will also appear on the "*Save*" button shown in each section you modify.

![](/media/activar_modo_multi_idioma/aviso_2_modo_multi_idioma.png?w=277&align=center)

![](/media/activar_modo_multi_idioma/aviso_modo_multi_idioma.png?w=409&align=center)

From now on you can edit your Event for each language separately. To change language, use the menu at the top right. You only need to translate the Event texts.

**IMPORTANT**: Generic information, such as dates, will be saved automatically in all available languages. Text content, such as the descriptions of schedule items or new pages, will not. Content that does not have a version in another language may not appear in the Event calendar, at least until something is written in its description and Save is clicked.

![](/media/panel_organizador/selector_idioma.png?w=300&align=center)

## Event language settings

First of all, you must choose the original language of the Event, that is, the one from which the data and milestones will be copied. Then you will be able to hide languages not available in the Event, either automatically or with manual control. Certain languages can be hidden from the Event menu. It is normal for an Event to be available in only some of the languages Symposium supports and, in fact, more may be offered in the future.

![](/media/panel_organizador/idioma_2.png?w=700&align=center)

Automatic control checks whether there is any text already saved in another language. If there is, it enables the version of the website in that language. Manual control, which is more advisable in this case, lets the Organizer decide which languages are available for the Event and which are not, regardless of whether they already have content.
