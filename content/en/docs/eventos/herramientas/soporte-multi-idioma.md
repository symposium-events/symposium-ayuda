Symposium uses the i18n model to translate the platform's texts, so that it can be adapted to different languages.

When we enable multi-language mode and create content, what we are actually doing is creating secondary versions of our event for the other languages. That is why every event needs a main language.

## How do I set the main language?

You must create the event content in an **original language** and never change it afterwards. The main language matters because it is the base language of the event: every other language version depends on it.

You select it when you create your event, in the creation form.

![](/media/freshdesk/soporte-multi-idioma-1.png?align=center)

It is essential to stay consistent with the main language. For example, you cannot start editing an event whose original language is English and then enter the first content in Spanish: the platform would assume that this Spanish content is the English version.

The tool cannot detect the language of the content automatically, so you have to enter each language's content in the right language for the platform to know which version belongs to which language.

## How do I enable multi-language mode?

Before you start creating content in other languages, you need to enable multi-language mode, which you will find in the "Tools" menu.

![](/media/freshdesk/soporte-multi-idioma-2.png?align=center)

Only once it is enabled can you start creating versions of your event in other languages.

**It is very important** that you start editing the content in other languages with the **event's basic details**, such as the title and description.

## How do I set a default language?

The language shown to visitors by default depends on each browser's settings. If, for example, a visitor is in an English-speaking region and their browser's default language is English, the event loads in that version, as long as there is content in that language; otherwise the original-language version is shown.

## Which content is translated automatically?

When we change the platform language, all predefined strings are translated automatically into any of the languages available in the language selector.

Every text that the tool provides by default, such as menus, help texts and sections, is already translated, so you only have to translate the content you have entered in the original language.

## Steps to edit the event in other languages

### 1. Enable multi-language mode

### 2. Select the language you are going to edit the event in

The language selector is on the right of the top navigation menu. Select the language you want to start editing the event in.

### 3. Edit the basic details first

Go to the **Basic data** section and start by editing the event title, the basic description and anything else you need.

### 4. Edit the other sections of the event

You can hide the platform languages you do not want to edit your event in. Just tick the hide option and select the languages you do not want to show in the website's drop-down.

![](/media/freshdesk/soporte-multi-idioma-3.png?align=center)

If you do not hide them, these languages remain available on your event page. When a visitor selects a secondary language, the tool first checks whether that language has content. If it does not, the event's original language is shown.
