All events created in Symposium follow a set structure as regards the sections of the Event menu: "Home", "Dates", "Schedule", etc. But if this layout does not fit the Event you are creating (for example, if the Event is a concert and has Artists instead of Speakers), the menu can be edited completely to change the labels and get around this problem.

## Editing the menu

Inside the Design group you will find *"Event menu"*.

![](/media/panel_organizador/menu_del_evento.png?w=250&align=center)

Each section or menu of the Event website is represented by a yellow box. This menu offers a number of tools:

- **Change the order**: to change the order of the sections, click and, without releasing, drag a yellow box up or down. This will determine how those menus appear on the Event website.
- **Edit the name**: to rename a menu, click the "Edit" button to the right of the item name.
- **Hide an item**: clicking "Hide" will hide a menu item on the Event website.
- **Limit the visibility of a menu to attendees only** who have confirmed their attendance at the Event.
- **Nest items inside a container**: if we add a container, using the "Add container" button, we can drag items inside this container so that they form a submenu.

Custom sections or [new pages](/docs/eventos/contenido/nuevas-paginas) created by the Organizer will be shown nested inside the "More..." submenu. To bring them up to the top level, they must be dragged out of the "More..." container. The same happens with the Files section, which by default will be shown inside the "Documentation" menu.

![](/media/panel_organizador/menu.png?w=500&align=center)

Each Event template has a maximum number of items that can be shown in the menu. If the menu is designed so that this maximum is exceeded, the items will be placed inside the "More" tab.
