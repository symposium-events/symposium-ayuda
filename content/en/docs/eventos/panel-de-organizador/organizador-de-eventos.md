Among the tabs that organize the users section we will find the "Organizer Panel" tab.

![](/media/organizador_de_eventos/organizador_eventos.png?w=650&align=center)

Inside it we will find the "Events I organize" section. There we will find a list of the events we organize or in which we take part as members of a committee.

The lists are grouped by organization date: "Upcoming" are those that will take place in the future and "Previous" are those that have already been held.

Next to the title of each event there are 3 buttons that let us perform a number of actions:

- VIEW: Lets us visit the event page.
- EDIT: Takes us to the editing panel of this event.
- DELETE: Lets us delete the event completely. An event can only be deleted if it has not made any sales and has no attendees.
