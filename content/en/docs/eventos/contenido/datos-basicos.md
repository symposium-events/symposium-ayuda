From this menu you can modify the initial data configured with the creation form during [event creation](/docs/eventos/creando-y-editando-un-evento/creando-un-evento-nuevo). There is more information about the visual content editor [here](/docs/eventos/contenido/editor-integrado).

![](/media/organizador_de_eventos/datos_basicos.png?w=250&align=center)

You can modify this data at any time, as many times as necessary. The data that can be modified from this menu is the following:

- Title and type of the event.
- Covers on which you want to publish your event, if the instance has more than one configured.
- Locations and format of the event.
- Organizer, contact details and custom web address.
- Categories and keywords.
- Dates and description of the event.

Once you have finished modifying the event, save the changes using the Save button at the bottom right of the form.
