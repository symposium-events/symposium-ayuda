Editing Sponsors is very similar to editing [Speakers](/docs/eventos/contenido/ponentes). With the same mechanics, the content of this section can be defined using a text editor or using an individual list of sponsors. Both contents are compatible and, if filled in, they will appear on the Event website: first the content of the All tab, then that of One by one.

![](/media/panel_organizador/patrocinadores.png?w=250&align=center)

At Symposium we always recommend entering Sponsors using the One by one method. This makes it easier to control how that content will look on the Event website and, in addition, the tool lets you define the order in which they will be shown on the event website.

For its part, at Symposium we consider it good practice to use the text editor of the All tab to write a rather generic introductory text without overusing the formatting options, which may not fit well with the general style of the Event page.

![](/media/patrocinadores/anadir_ponente.png?w=642&align=center)

For a Sponsor, it is possible to show an image or corporate logo, their name and a link to their website.

The Sponsors section will appear on the Event website only if some content has been registered. The Sponsors widget will also appear in the Home section. In addition, depending on the template used, they may be visible in the footer of the event page.

## Ordering sponsors

You can set the order of priority in which you want the event Sponsors to appear. When you have finished entering the data for all of them, you will get a list. You can drag and drop any of the items to change the order as you see fit.

![](/media/patrocinadores/patrocinadores_orden.png?w=750&align=center)
