The platform supports several languages, which are added to the language menu as they become available. The language selection menu appears at the top of the portal pages (except in the views of an event, since that depends on the template or theme used).

![](/media/seleccion_003.png?align=center)

If we click on one of the languages, the portal is translated into that language; and if the event we are viewing has multi-language support enabled, we will see the version of the event for the selected language.

The language selector is also used when we edit an event that has [multi-language support](/docs/eventos/herramientas/activar-modo-multi-idioma) enabled, so that we can edit the version of the event for the selected language.

The platform selects the language automatically. When a new user arrives on the platform, the system detects the language configured in their browser and shows the portal in the right language. If the browser language is not one of the languages supported by the platform, the default language configured for their institution is applied.

If we want a language setting other than the one auto-detected from the browser, we can select the language from the language menu or, if we have a user account on the platform, set in the user settings the language to use every time we log in to the system.

Language selection therefore follows this priority: first it checks whether the user has a language configured; if not, it checks whether a language has been selected through the language menu; and finally, if no language has been selected manually, it is detected from the browser settings.
